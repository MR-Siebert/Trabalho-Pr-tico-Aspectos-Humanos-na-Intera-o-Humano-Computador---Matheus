# Sistema de Admissão de Emergência

Este projeto aplica conceitos de IHC (Interação Humano-Computador) na criação de uma interface para recepção hospitalar sob estresse.

## Pilares Aplicados

### 1. Gestalt e Percepção
Uso de Fieldsets para agrupar informações por proximidade e similaridade.

### 2. Uso Eficiente de Cores
Somente a ação primária possui alto contraste.
Erros utilizam texto + símbolo ⚠ além da cor vermelha.

### 3. Memória e Chunking
CPF e telefone possuem máscara automática, reduzindo carga de memória.

### 4. Foco e Atenção
Ausência de menus ou animações.
Layout simples e direto.

### 5. Redução da Carga Cognitiva
Uso de Progressive Disclosure para informações não emergenciais.

## Técnica mais desafiadora

A técnica mais desafiadora foi equilibrar a redução da carga cognitiva com a necessidade de coletar informações completas, especialmente ao decidir quais campos deveriam ser ocultados inicialmente via Progressive Disclosure.
